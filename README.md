🎯 Python Quiz Game

A simple and interactive Quiz Game built with Python.
The game asks multiple-choice questions, checks the user's answers, and displays the final score.

🚀 Features

- 🎮 Interactive quiz gameplay
- ❓ Multiple-choice questions
- ✅ Automatic answer checking
- 📊 Score calculation
- 🏆 Final score display
- 🔄 Easy to add new questions
- 🖥️ Simple and beginner-friendly Python project

🛠️ Technologies Used

- Python 3
- Tkinter — for the graphical user interface (GUI), if using the visual version

⚙️ How to Run

1. Install Python

Download and install Python 3 from the official Python website.

2. Open the Project

Open the project folder in Visual Studio Code.

3. Run the Program

Open the VS Code terminal and run:

python quiz_game.py

If your system uses "python3", run:

python3 quiz_game.py

🎮 How to Play

1. Start the quiz.
2. Read each question carefully.
3. Select the correct option.
4. Submit your answer.
5. Continue until all questions are completed.
6. Your final score will be displayed.

📊 Scoring

The score is calculated based on the number of correct answers.

Score = Correct Answers / Total Questions × 100

Example:

Correct Answers: 8
Total Questions: 10

Score: 80%
